# PCB tools v0.1.0-rc.1

First pilot prerelease, 2026-11-05. This consolidates the completed designer and reviewer tools on `main` so pilot boards can use a tagged, reproducible version.

## Included

- All previously merged tools, plus copper checks for via-in-pad, edge margins, ground islands and pin-1 marks; CPL orientation from cached part data; opt-in block planning and gates.
- Regeneration checks reject overlapping output paths, traversal and symlink escapes.
- Block gates fail when checks cannot run and bind acceptance history to the board, plan and configuration.
- IR-drop calculations isolate scratch files and resolve paths before changing directories.
- Routing resolves board/output paths before invoking external engines. A failed Specctra import preserves diagnostics and cannot report or save a successful output.
- Track UUID canonicalization updates ordinary group membership without rewriting unrelated text.
- Stitch and ground-island passes report measured `setup_changed` values. Final-state comparison and candidate selection behavior are unchanged.
- Portable router regression tests cover eight path combinations, successful/failed/stale imports, group identity, and ten postpass scenarios with 28 measurements. These dependency-controlled tests complement native KiCad integration checks; they do not simulate physical routing quality.

## Install and reproduce

Check out tag `v0.1.0-rc.1` and follow the repository README. Supported validation environment: macOS, KiCad 10.0.1 with its bundled Python/pcbnew, Diode pcb 0.4.97, KiCadRoutingTools 0.23.7, and the external routing tools described in `tools/bench/README.md`. External programs and fabrication rule packs are not bundled.

The full suite additionally needs the archived run fixtures at `RUNS` and reference repositories at `REF`. Some archived regeneration scripts also require the rule pack at the default `/tmp/pcb-ref/kicad-druid` path. Missing fixtures are not a passing validation result. The references used for release validation are:

- `Cimos/kicad-druid` at `8af046d6a1839320a360a4b6790ac11eb27a78ae`.
- `Every-Flavor-Robotics/motorgo-plink-hardware` at `0250d756ace96c666edb3695f35ecafd1c039d3d`.

```sh
sh tools/verify_all.sh route_regressions.sh
REF=/path/to/reference-repositories KICAD_DRUID=/path/to/reference-repositories/kicad-druid sh tools/verify_all.sh
```

- Replay bench: all existing assertions pass, including zero false fails. Known undetected defects remain documented by the bench; this is not complete fault coverage.

## Pilot limits

This is a release candidate for supervised trials. Neither a clean routing verdict nor an attractive render proves a board is ready to order. Check inherited DRC errors, the fabrication rule pack, declared electrical constraints, sourcing, assembly orientation, and regeneration on the final deliverables. Electrical performance and manufacturing acceptance still require review and physical testing.

The setup comparison covers measured board minimums, not every field in the original project. Block planning remains opt-in. Routing postprocessing can change the quality of a candidate; independently check the selected final board. This release does not change routing budgets, timeouts, external-engine versions, candidate selection, or native export/save behavior.

Start with the simpler pilot board. Advance to the complex pilot only after reviewing the first result with the project owner.
