## Guardrails learned (enforce them in tools, not prose)
- Never open the KiCad GUI from a script. `pcb layout` opens pcbnew unless `--no-open` (P0-T6). KiCad rewrites files
  from memory on save, so a stray window corrupts scripted edits.
- A `.kicad_dru` fab pack **replaces** board-setup constraints; both rung-1 designers reported "DRC 0" with the pack
  loaded while 18 and 20 errors existed under the project's own rules (R1-S1-F1, R1-Z1-F1). Always run DRC plain and
  packed, report both, and refuse a pack value below the board setup.
- A rejected `.kicad_dru` makes `kicad-cli pcb drc` exit 0 silently; append a sentinel rule that must fire (P0-T5).
- "Code is the source of truth" is only true if regeneration works from a clean checkout (R1-Z1-F2).
- Designers overclaim in prose (R1-S1-F2); every claim becomes a measured row.
- Baseline runs must not be able to read this repo (R1-S1-T8).
- Edit-safety: netlist connectivity diff on every scripted schematic edit (`/tmp/pcb-ref/pace-racer-hardware/tools/verify_netlist.py`, P0-T3).
